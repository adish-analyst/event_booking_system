# Event Booking System

A simple Event Booking System developed using PHP and MySQL.

## Features
- User Registration
- User Login
- Event Listing
- Event Booking
- Responsive UI Design

## Technologies Used
- PHP
- MySQL
- HTML
- CSS
- XAMPP

## Project Description
This project allows users to register, login, view available events, and book events online. The system is connected with MySQL database for storing user and event details.
